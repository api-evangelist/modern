# MODERN Partner API

> MODERN (modernis.com) is a two-way customer interaction platform for heavy-equipment dealerships across construction, agriculture, mining, landscaping, and material handling. The Partner API lets authorized integrators read dealership dashboards, manage service work orders, post work-order events, send customer notifications, and maintain technicians and notes on a franchise's behalf.

## Authentication
- Exchange a franchise username/password via HTTP Basic auth against POST /token to receive a bearer access token (valid 24 hours, scoped to a single franchise).
- All /v1/* endpoints require the bearer token.
- Every response returns a Modern-Request-Log-ID header used for support.
